# H1/H2 假设实验登记

**登记类型：** 预先规定的研究假设与程序行为诊断，不是策略有效性结论。

**当前状态：** `NEEDS_DATA`。正式基线保持 `NOT_READY`，增量续跑保持 `can_continue=false`。

## 固定范围

本轮使用的 2024-10-08 至 2025-01-10 沪深快照已经用于开发和实现调试，不能作为独立留出。真实覆盖审计只报告输入覆盖和阻断原因，不计算收益、夏普、回撤或优劣比较。后续真实实验需在实现和准入门槛冻结后另选区间，或从未来起开始前瞻纸面记录。

### H1：停牌窗口筛选

- **控制组：** 使用冻结的原候选池和排名。
- **候选组：** 信号日及此前 20 个开市日须对应 21 个唯一行情日，收盘价和复权收盘价均为有限正数；窗口内停牌状态均明确且非停牌。缺行情、重复日、无效价格、停牌或未知状态均不能进入候选组。
- **报告指标：** 按信号日和范围（全体已分类股票成员、原候选）报告完整窗口数、缺行情、重复、停牌、状态未知和类型未知成员。
- **解释边界：** `ELIGIBLE_FOR_H1_DIAGNOSTIC` 只表示数据行满足这项程序规则，不代表点时状态和供应商历史版本已通过验证。

### H2：零股目标后的延迟补位

- **控制组：** 前 N 名按原目标计算；舍入后为零的目标保留现金。
- **候选组：** 决策日检查排名候选，选择可形成正数量的首个候补，冻结代码与数量，在再下一开市日按明示的开盘价假设检查预算并生成模拟结果。
- **日历规则：** 信号日、决策日、执行日必须是规范交易日历中的连续三个开市日。决策报价时间、证券状态时间和执行报价时间分别检查。
- **解释边界：** 原策略对比衡量“候补选择 + 执行延迟”的整体变化，不能把结果单独归因为补位。另提供相同后续期限的现金保留控制组；此比较仍受报价、规则和费用假设限制。
- **执行标签：** 订单为 `SCHEDULED_SIMULATED_ORDER`；以开盘价假设计算的模拟结果为 `SIMULATED_FILL_UNDER_OPEN_PRICE_ASSUMPTION`。该状态不是实际可成交证明。

## 每个实验必须登记的内容

```text
experiment_id / hypothesis_id / hypothesis_version
代码提交和工作区状态
配置及策略参数摘要
数据、股票池、交易日历、规则、费用和公司行动版本/哈希
文件原始哈希与规范化摘要
信号、排名、决策和执行日期及时区
价格来源/可得时间与状态来源/可得时间（分开）
控制组和候选组唯一规则差异
初始假设现金/持仓、交易单位、费用和执行假设
输入缺口、停止条件、结果类型及人工审核状态
```

排序文件在审计后重建时，必须写明 `UNVERIFIED_RECONSTRUCTED_AFTER_RUN`，不能把重建时哈希说成原实验运行时锚点。摘要数字也不能替代输入文件与源版本绑定。

## 停止条件

以下任一项未满足时，运行最多可作为受限数据/程序诊断，不得输出策略优劣结论：

1. 决策时点的行情与候选排名来源没有可信可得时间证据；
2. 按日期的上市、停牌、ST、买入能力或交易单位状态缺失/未知；
3. 历史涨跌幅、交易单位、价格限制或有效日期费用不完整；
4. 行情窗口与交易日历不连续，或公司行动覆盖与价格口径未满足假设；
5. 候选与控制使用不同的输入、执行模型或初始状态，且差异没有预先登记。

`human_review_required=true`、`may_modify_active_strategy=false`、`may_generate_orders=false` 始终保持。任何通过研究准入的候选仍需单独建版本并由用户审核；不连接券商。
