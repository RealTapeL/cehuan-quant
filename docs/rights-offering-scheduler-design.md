# 配股事件每日调度（合成诊断已接入）

## 状态与边界

`RightsOfferingEvent`、CSV 适配器、`AccountingEventSchedule` 和 `ledger_v2` 已接通。当前实现仅由合成数据验证，属于非正式研究诊断；没有真实公告小样签认、全市场事件覆盖、历史规则与费用核验，也不开放正式基线。

配股的研究组合处理必须由事先冻结的事件决策配置驱动。真实华泰账户的实际认购、缴款和获配数量只能由成交/资金/持仓证据导入，不能用研究策略配置代替。

当前 `RightsOfferingDecision` 绑定事件 ID、处置、执行日期、费用及可选获配依据；CSV 与 checkpoint 会绑定这些值，但还没有独立的决策首次可得时间或审核证据字段。因此当前决策时间点仅由合成实验配置给定，不足以证明真实历史决策在当时已冻结。

## 输入契约

继续复用 `RightsOfferingEvent` 的事件 ID、证券代码、登记日、认购开始/截止日、可流通日、每股配股比例、认购价格、`known_at_utc` 和 `ActionSource`。接入 CSV 时另需：

- 显式决策：`SUBSCRIBE`、`DECLINE` 或 `MANUAL_REVIEW`。没有决策行时维持 `RIGHTS_DISPOSITION_REQUIRED`，不能静默自动选择。
- 决策适用研究账户/策略版本及配置哈希。
- 非整数权利的账户层最终分配数及其来源；没有结果时保持未知。
- 认购费用及其有效日期来源；不能从普通买卖佣金推定配股费用。
- 首次可得证据、原件归档路径和哈希、字段审核状态、审核人及日期。
- 如事件在窗口结束后才完成配股登记或可流通，期末必须保留待处理权利；无合格估值时不汇总完整 NAV。

事件原件哈希只证明文件字节一致。公告日期、认购期、比例、价格和上市日期仍需人工核对。若事件更正影响已处理登记日，checkpoint 必须回溯重算。

## 每日账务顺序

1. **决策可得时点检查**：只有在当时已知且来源通过审核的事件，才能进入研究调度。决策配置必须在认购开始前冻结；用户账户的实际选择单独导入。
2. **登记日收盘**：先处理当日模拟成交，再以收盘后剩余批次调用 `record_rights_offering()`，生成资格快照和待处置权利。登记日收盘卖出的股份不进入快照。
3. **认购期**：经冻结的 `SUBSCRIBE` 决策在指定认购交易日记载缴款；核对现金、精确可认购股数和明确费用。现金不足时整笔失败，不融资，也不自动部分认购。
4. **放弃**：只有认购期结束后才可按当前账本规则将权利记为 `DECLINE`；期间内不把未操作解释成已放弃。
5. **人工处理**：`MANUAL_REVIEW` 保留未决权利，不自动认购或放弃。其对组合权益的估值若没有可靠方法，则相关 NAV 保持未估值/阻断。
6. **股份登记日**：只有已认购并确认最终登记数量的配股股份，才调用 `allot_rights_shares()` 并生成独立持仓批次；登记流水记在登记日。批次的 `sellable_from` 是公告可流通日，不能提前开放卖出。
7. **日终核对**：检查现金变化、权益数量、成本、权利状态和流水幂等键。公司行动本身不得生成普通买卖成交、佣金或成交次数。

## 账本映射与当前限制

| 阶段 | 账本操作/状态 | 当前已有能力 | 调度接入前需解决 |
|---|---|---|---|
| 登记日快照 | `record_rights_offering` / `RIGHTS_DISPOSITION_REQUIRED` | 按持仓批次保存权利，并绑定来源 ID/哈希 | 已支持；需真实来源审核后才能用于真实公告诊断 |
| 认购 | `decide_rights_offering(SUBSCRIBE)` / `SUBSCRIBED_PENDING_ALLOTMENT` | 校验认购期间、股数及现金，扣除缴款和明确费用 | 不支持自动部分认购；事件决策哈希参与 checkpoint 输入绑定 |
| 放弃 | `decide_rights_offering(DECLINE)` / `CANCELLED` | 仅在认购期结束后确认失效 | 未决状态不会自动转成放弃 |
| 股份登记 | `allot_rights_shares` / `SETTLED` | 登记日生成独立批次并转入成本 | 已与可流通日分开；登记日不产生普通成交或佣金 |
| 可流通 | `PositionLot.sellable_from` | 可流通日开放卖出数量 | 登记后、可流通日前仍不可卖 |
| 估值 | `NoncashClaim` | 记录代理方法、报价日期、证券、来源及规范报价摘要 | `RIGHTS_INTRINSIC_CLOSE_PROXY` / `UNDERLYING_CLOSE_PENDING_SHARES_PROXY` 是研究假设，不是权利成交价；真实估值规则未验证 |

当前 `decide_rights_offering()` 要求非整数权利有账户层获配股数和证据；整数权利按完整权利认购，尚不支持部分认购。若研究需要部分认购，先扩展事件/决策模型与账本账务，再接调度。

## 验收矩阵

- 登记日持仓快照按批次正确；登记日成交时序边界明确。
- 足额现金认购后现金减少 `获配股数 × 配股价 + 配股费用`，可流通日前不增加可卖数量，可流通日生成相应批次。
- 现金不足时明确阻断，不融资、不自动减量。
- 明确放弃只在认购期结束后记账；缺少决策保持未决并阻断正式净值。
- 非整数获配无账户/结算依据、费用来源缺失、原件哈希错误、公告审核未完成均在进入调度前拒绝。
- 登记日后原持仓卖出不改变已经确定的配股权利快照。
- 同一事件重复调度不重复扣现金、发股或写入权益；导入修正时定位受影响日期并要求回溯。
- 认购期、checkpoint 和可流通日跨研究窗口时，连续运行与 checkpoint 续跑的成交、现金、权利、持仓成本和 NAV 一致。
- 每个未决权利在报告中列出事件、股数、来源、下一阶段日期及估值状态；没有可信估值时标记未估值，不输出完整策略绩效结论。

## 实施次序

1. checkpoint 仍绑定完整事件表；增量预检仅报告，不放行续跑。
2. 当前合成集成测试覆盖显式认购、现金不足、权利快照、跨 checkpoint、登记与可流通日期以及连续/分段运行一致性。
3. 对照少量人工签认公告字段后，再准备短区间研究诊断；真实账户结果仍以脱敏账户资料为准。
4. 部分认购、真实配股费用规则、真实权利估值、真实事件覆盖仍需单独设计和核验。全市场事件覆盖、历史交易规则、费率和完整账务门槛通过之前，正式基线保持 `NOT_READY`。
