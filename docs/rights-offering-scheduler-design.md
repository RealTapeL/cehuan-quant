# 配股事件每日调度设计（尚未接入）

## 状态与边界

账本已经提供 `RightsOfferingEvent`、登记日权利快照、显式 `SUBSCRIBE`/`DECLINE` 处理及可流通日登记方法；当前 `AccountingEventSchedule` 和回测引擎不接受配股事件。本文是后续实现契约，不代表当前 CLI 已支持配股调度。

配股的研究组合处理必须由事先冻结的事件决策配置驱动。真实华泰账户的实际认购、缴款和获配数量只能由成交/资金/持仓证据导入，不能用研究策略配置代替。

## 输入契约

继续复用 `RightsOfferingEvent` 的事件 ID、证券代码、登记日、认购开始/截止日、可流通日、每股配股比例、认购价格、`known_at_utc` 和 `ActionSource`。接入 CSV 时另需：

- 显式决策：`SUBSCRIBE`、`DECLINE` 或 `MANUAL_REVIEW`；缺省视为 `MANUAL_REVIEW`，不能静默自动选择。
- 决策适用研究账户/策略版本及配置哈希。
- 非整数权利的账户层最终分配数及其来源；没有结果时保持未知。
- 认购费用及其有效日期来源；不能从普通买卖佣金推定配股费用。
- 首次可得证据、原件归档路径和哈希、字段审核状态、审核人及日期。
- 如事件在窗口结束后才完成配股登记或可流通，期末必须保留待处理权利；无合格估值时不汇总完整 NAV。

事件原件哈希只证明文件字节一致。公告日期、认购期、比例、价格和上市日期仍需人工核对。若事件更正影响已处理登记日，checkpoint 必须回溯重算。

## 每日账务顺序

1. **决策可得时点检查**：只有在当时已知且来源通过审核的事件，才能进入研究调度。决策配置必须在认购开始前冻结；用户账户的实际选择单独导入。
2. **登记日收盘**：先处理当日模拟成交，再以收盘后剩余批次调用 `record_rights_offering()`，生成资格快照和待处置权利。登记日收盘卖出的股份不进入快照。
3. **认购期**：`SUBSCRIBE` 在配置指定的认购交易日记载缴款；核对现金、精确可认购股数和适用费用。当前账本方法在现金不足时失败，不做融资，也不自动部分认购。
4. **放弃**：只有认购期结束后才可按当前账本规则将权利记为 `DECLINE`；期间内不把未操作解释成已放弃。
5. **人工处理**：`MANUAL_REVIEW` 保留未决权利，不自动认购或放弃。其对组合权益的估值若没有可靠方法，则相关 NAV 保持未估值/阻断。
6. **可流通日**：只有已认购并确认最终登记数量的配股股份，才调用 `allot_rights_shares()` 并生成可卖批次。不能根据预计配股数提前开放卖出。
7. **日终核对**：检查现金变化、权益数量、成本、权利状态和流水幂等键。公司行动本身不得生成普通买卖成交、佣金或成交次数。

## 账本映射与当前限制

| 阶段 | 账本操作/状态 | 当前已有能力 | 调度接入前需解决 |
|---|---|---|---|
| 登记日快照 | `record_rights_offering` / `RIGHTS_DISPOSITION_REQUIRED` | 按持仓批次保存权利 | 事件 CSV、每日索引、窗口外阶段状态 |
| 认购 | `decide_rights_offering(SUBSCRIBE)` / `SUBSCRIBED_PENDING_ALLOTMENT` | 校验认购期间、整数获配、现金充足并扣现金 | 订阅费用按日期和来源、固定研究决策日、部分认购契约 |
| 放弃 | `decide_rights_offering(DECLINE)` / `CANCELLED` | 截止日后确认失效 | 自动调度不得把未决变成放弃 |
| 登记/可流通 | `allot_rights_shares` / `SETTLED` | 确认股数后生成批次 | CSV 必须区分登记日和可流通日；当前事件只明确建模 `tradable_date` |
| 估值 | `NoncashClaim` | 配股权利可在登记日建立 | 当前没有已审核的权利公允估值规则；未决权利不能记零后继续给完整 NAV |

当前 `decide_rights_offering()` 要求非整数权利有账户层获配股数和证据；整数权利按完整权利认购，尚不支持部分认购。若研究需要部分认购，先扩展事件/决策模型与账本账务，再接调度。

## 验收矩阵

- 登记日持仓快照按批次正确；登记日成交时序边界明确。
- 足额现金认购后现金减少 `获配股数 × 配股价 + 配股费用`，可流通日前不增加可卖数量，可流通日生成相应批次。
- 现金不足时明确阻断，不融资、不自动减量。
- 明确放弃只在认购期结束后记账；缺少决策保持未决并阻断正式净值。
- 非整数获配无账户/结算依据、费用来源缺失、原件哈希错误、公告审核未完成均在进入调度前拒绝。
- 登记日后原持仓卖出不改变已经确定的配股权利快照。
- 同一事件重复调度不重复扣现金、发股或写入权益；导入修正时定位受影响日期并要求回溯。
- 认购期、checkpoint 和可流通日跨研究窗口时，连续运行与 checkpoint 续跑的成交、现金、权利、持仓成本和 NAV 一致。
- 每个未决权利在报告中列出事件、股数、来源、下一阶段日期及估值状态；没有可信估值时标记未估值，不输出完整策略绩效结论。
