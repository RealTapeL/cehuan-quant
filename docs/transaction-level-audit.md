# 真实行情短窗口逐笔审计

> **更正说明（2026-11-04）：** 本文下方历史版本中的登记日权益匹配解释已被[登记日权益边界更正记录](record-date-entitlement-correction.md)取代。旧文依据一份 2006 年测试用 DVP 材料把“登记日买入不享有、登记日卖出仍享有”作为唯一口径；后续审查发现官方材料对登记日当日交易的描述并不完全一致。审计工具现按模拟登记日收盘持仓区间生成“可能匹配”，不把结果当作账户权益确认。旧报告原文保留以记录审计历史。正式基线仍为 `NOT_READY`。

## 目的与范围

本记录总结一次只读审计：把冻结研究运行中的模拟成交，连接到可重建信号、行情行、市场规则回退、费用假设、候选池和账本记录。它不是策略业绩评价，也没有重跑回测或生成新的交易计划。

评价窗口为 2024-10-08 至 2025-01-10，共 68 个交易日、5,128 个证券代码和 347,660 行行情；原运行包含 24 笔模拟成交。详细成交、代码、原始供应商响应和公告 PDF 留在 Git 忽略的 `data/private/`，不提交到本仓库。

## 已复核结果

- 24 笔模拟成交逐笔连接到原账本流水。冻结的核心数据、日历、策略配置、成交、账本、阻断单和指标文件均与此前文件清单中的 SHA-256 相符。
- 三个信号日的候选排名由冻结行情和配置重建，分别有 1,812、3,242 和 970 个合格候选；证券、排名和动量与保存的候选表一致。保存的候选表本身不在此前清单中，因此只确认“按输入可重建一致”，不声称候选 CSV 原文件已由旧清单封存。
- 候选快照有 6,024 行、4,313 个不同证券。对三个调仓日各五个目标槽按 100 股交易单位假设重建时，有一个选中目标被舍入为 0 股。原阻断订单文件为 0 行，没有记录这类被跳过目标；逐目标审计现已将其显示出来。
- 24 笔成交总模拟成交额为 ¥166,409.86，配置费率计算的模拟费用为 ¥151.82，模拟滑点价格影响为 ¥83.19。三者均为研究模拟值，不是华泰账单或实际成交。
- 347,660 行行情均使用配置中的市场规则回退；24 笔成交均使用配置平费率假设。历史板块规则、价格限制、交易单位和华泰个人费率没有在该运行中得到独立核验。
- 腾讯历史日线经 AKShare 获取后，成交日 24/24 行的原始 OHLC 与冻结行情逐项相同。成交量/成交额按记录的容差比较；两个深市代码的 AKShare 输出疑似把成交量以“手”表示，审计单独记录了 ×100 的单位归一，没有把它藏在价格比较里。这个当前查询只说明两份现有接口数据相符，不证明 2024 年历史发布版本相同。
- CNINFO 结构化分红/送转接口对 15 个选中目标均查询成功，返回 150 条历史记录；在实际持仓区间和对应信号观察窗内未发现该接口记录的事件日期命中。该接口不覆盖全部公司行动，不能据此断言不存在配股、并购换股、停复牌、退市或其他事件。
- 原运行的公司行动来源登记表为 0 行；本轮外部查询仅补充有限的分红/送转检查及一份重组停牌公告，不能把原空登记表视为无事件证明。
- 持仓与分红事件的匹配以股权登记日为权益判断点；审计对“登记日买入不享有、登记日卖出仍可能享有”单独处理，避免用当天收盘持仓区间误排除权益。相关结算说明见[深交所 T+1 货银对付材料](https://www.szse.cn/marketServices/technicalservice/doc/P020180328467503044665.pdf)。该匹配是研究审计提示，账户最终权益仍以结算和账户记录核实。
- 一条官方发行人公告记录了观察窗内某个高排名候选的重大资产重组筹划，以及自 2024-10-08 继续停牌的安排。行情快照对应 20 日动量观察区间内包含 7 个停牌交易日。公告日期不等于精确首次公开时刻；来源 PDF 已在私有审计包归档，字段人工审核仍为 `PENDING`。这不是该窗口中已确认的现金或股份账务事件，但足以说明候选池审计不能只查最终成交和空白事件登记表。

## 时点与可信度

适配器把日线 `available_at` 填为交易日 15:00（Asia/Shanghai），计划接口会用它阻止早于此时刻生成计划；这是程序的收盘可用假设。`retrieved_at_utc` 记录本次抓取时间。它们都不能证明供应商当时已发布同一历史数据版本。本次外部行情查询发生在历史窗口之后，历史 vintage 和历史决策时点可得性仍为 `UNVERIFIED`。

审计报告将“核心运行文件哈希匹配”“候选排名可重建”“历史数据可得性”“规则/费率覆盖”“公司行动覆盖”分开标记。候选文件缺少先前哈希锚点；市场规则使用回退，个人费用未知，公司行动查询范围有限。结论保持：正式基线 `NOT_READY`，增量续跑 `can_continue=false`。

本次审计没有修改冻结行情、checkpoint、原运行或旧报告，没有接入券商，不执行委托。新运行的 `metrics.json` 会附带结构化 `research_trust` 标签；这个既有冻结运行没有被重新计算或改写。

## 私有复核产物

可在本机 `data/private/experiments/` 下查看 `summary.md`、`trade-audit-summary.json`、逐笔 `trade-audit.csv`、候选排名与目标对账、持仓区间、独立报价对照、CNINFO 查询日志、原始响应和 `audit-artifact-inventory.csv`。原始文件的哈希清单可验证字节完整性，但不替代来源解释或人工签认。

以新输出目录运行审计脚本时，目录必须是尚不存在的路径，避免覆盖既有审计包：

```bash
uv run python scripts/audit_real_trade_trace.py \
  --experiment-dir data/private/experiments/<experiment> \
  --run-dir data/private/experiments/<experiment>/<frozen-run> \
  --candidate-pool data/private/experiments/<experiment>/<prior-audit>/candidate-pool-by-signal.csv \
  --output-dir data/private/experiments/<experiment>/trade-audit-<new-id> \
  --supplemental-filings /private/path/supplemental-filings.json \
  --fetch-independent-sources
```

`--supplemental-filings` 是可选的本地 JSON 证据清单；它不会从策略输出推测事件。清单格式应包含 `schema_version=1` 及 `filings` 数组，每项提供证券、事件类型、公告标题、HTTPS URL 和公告文档日期，并可注明待核查区间命中与时点证据状态。公告首次可得时刻没有可靠证据时继续标为未知。

## 研究假设接口

本轮同时定义了策略研究 Agent 的 JSON 输入/输出 schema 和合成示例。它只规范化“数据可信度、冻结策略、既有研究摘要 → 待审核假设”的边界；没有连接 RD-Agent 或语言模型，也不会修改策略配置、自动运行回测或生成券商委托。
