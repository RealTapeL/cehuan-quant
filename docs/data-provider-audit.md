# 数据源权限与覆盖审计

审计时间：2026-10-29（Asia/Shanghai）。运行环境为 Arch Linux，项目环境由 uv 管理，Python 3.11.15。以下是本机实测，不代表供应商持续可用性。

## 结论

- 本机没有安装 Tushare，也未发现 `TUSHARE_TOKEN`；Tushare 账户积分和接口权限未知。本次没有购买数据权限，也没有要求用户发送 Token。
- AKShare 仍是项目原有数据适配层。仓库先前记录的实测显示，东方财富接口发生代理断连；腾讯接口可返回样例日线，但不同源的后复权绝对价不一致，不能拼接序列。
- BaoStock 0.9.4 在本机无需用户 Token 即登录成功，成功返回日线、复权因子、交易日历和证券基础资料。本次选它生成私有研究快照。PyPI 将该版本标为 Alpha，且发布文件没有 provenance；程序包 BSD 标记不等于行情数据可任意再分发。应继续保留本地原始快照，不公开上传。
- BaoStock 日线提供 `tradestatus` 与 `isST`，股票基础资料提供 `ipoDate`、`outDate`；实测仍未得到逐证券逐日涨跌停价格、交易单位或带有效期的完整市场规则。因此，本数据可用于数据管道验证和有限回测诊断，不能用于生成合规的人工交易计划。

## 独立案例核验

- 涨幅异常：`SZ301551`（无线传媒）在 2024-10-08 收盘 228.01 元、2024-10-09 收盘 80.99 元，单日收盘变化 -64.48%。BaoStock 快照与 AKShare 腾讯历史行情对这两天 OHLC 完全一致；[深交所上市公告](https://www.szse.cn/disclosure/notice/company/t20240925_609600.html)确认其上市日为 2024-09-26，10-09 是上市后第 5 个交易日。[深交所规则问答](https://www.szse.cn/www/investor/knowledge/stock/deal/t20230525_600599.html)说明新股前五个交易日不设价格涨跌幅限制。因此，这条警告对应真实大幅波动和特殊上市规则，当前证据不支持将其判为错价。AKShare 东方财富端本次通过本机代理连接失败，未提供独立确认。
- ST 与长期停牌：`SH600289`（亿阳信通）2024-10-08 的 BaoStock 日线 `isST=1`。[发行人 2024-10-24 公告](https://big5.sse.com.cn/site/cht/www.sse.com.cn/disclosure/listedinfo/announcement/c/new/2024-10-24/600289_20241024_NLXY.pdf)使用 `*ST信通` 名称；2024-11-11 起至 2025-01-10，快照的 44 个开市日都标记停牌。[发行人 2024-12-21 公告](https://static.cninfo.com.cn/finalpage/2024-12-21/1222091475.PDF)确认停牌起始日为 2024-11-11；[公司 2025-01-13 公告](https://big5.sse.com.cn/site/cht/www.sse.com.cn/disclosure/listedinfo/announcement/c/new/2025-01-13/600289_20250113_J87W.pdf)说明 2025-01-14 复牌。这里名单名称未带星号，但日线 `isST` 和发行人公告相符，显示名称字段不能代替 ST 状态字段。
- 后来退市：`SZ000413`（ST旭电）仍出现在日期名单 2024-10-11，名单 `tradeStatus=0`，日线保留停牌结转价 0.37 元，`isST=1`；BaoStock 基础资料回报 `outDate=2024-10-11`。[发行人摘牌公告](https://static.cninfo.com.cn/finalpage/2024-10-11/1221359894.PDF)确认当日摘牌。该例证明退市日/停牌样本未被当前证券列表过滤掉；基础资料是本次快照时获取的字段，不应误称为当日发布的数据。

逐行机器可读证据保存在忽略目录 `data/private/audits/point-in-time-case-audit-202410-v1/case_audit.json`；腾讯行情副本及哈希在相邻目录 `price-anomaly-301551-202410-v1/`。以上是针对具体案例的抽查，不构成供应商整体完整性证明。

BaoStock 官方 API 入口列有每日更新、历史 A 股 K 线和访问统计说明：[API 文档入口](https://www.baostock.com/api/)。官方证券基础资料文档列出上市日、退市日、类型和状态：[证券基本资料](https://www.baostock.com/mainContent?file=stockBasic.md)。官方复权说明提供复权因子查询及按原始日线构造复权价格的示例：[复权因子](https://www.baostock.com/mainContent?file=factorInfo.md)。官方[访问限制说明](https://www.baostock.com/blacklist)列出单日请求数和并发访问限制。包版本、Alpha 标记、免费数据描述及无发布 provenance 可在 [PyPI 项目页](https://pypi.org/project/baostock/)核对。

Tushare 官方接口分别列出股票基础信息、交易日历、停复牌、涨跌停价和历史 ST 数据：[股票基础信息](https://tushare.pro/document/1?doc_id=25)、[交易日历](https://tushare.pro/document/2?doc_id=26)、[每日停复牌](https://tushare.pro/document/2?doc_id=214)、[每日涨跌停价](https://tushare.pro/document/2?doc_id=183)、[历史 ST 名单](https://tushare.pro/document/2?doc_id=397)。当前官方权限表显示 `stock_basic` 和 `stk_limit` 的门槛为 2,000 积分起，`stock_st` 为 3,000 起；日线 `daily` 为 120 起，通用复权行情 `pro_bar` 为 2,000 起。积分只是接口最低权限门槛，实际频次随积分变化；本机未安装 Tushare 且没有可用 Token，因此未验证任何账户权限，也不据此推断用户拥有访问权。[Tushare 积分权限表](https://tushare.pro/document/1?doc_id=108)
