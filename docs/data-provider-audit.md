# 数据源权限与覆盖审计

审计时间：2026-10-27（Asia/Shanghai）。运行环境为 Arch Linux，项目环境由 uv 管理，Python 3.11.15。以下是本机实测，不代表供应商持续可用性。

## 结论

- 本机没有安装 Tushare，也未发现 `TUSHARE_TOKEN`；Tushare 账户积分和接口权限未知。本次没有购买数据权限，也没有要求用户发送 Token。
- AKShare 仍是项目原有数据适配层。仓库先前记录的实测显示，东方财富接口发生代理断连；腾讯接口可返回样例日线，但不同源的后复权绝对价不一致，不能拼接序列。
- BaoStock 0.9.4 在本机无需用户 Token 即登录成功，成功返回日线、复权因子、交易日历和证券基础资料。本次选它生成私有研究快照。PyPI 将该版本标为 Alpha，且发布文件没有 provenance；程序包 BSD 标记不等于行情数据可任意再分发。应继续保留本地原始快照，不公开上传。
- BaoStock 日线提供 `tradestatus` 与 `isST`，股票基础资料提供 `ipoDate`、`outDate`；实测仍未得到逐证券逐日涨跌停价格、交易单位或带有效期的完整市场规则。因此，本数据可用于数据管道验证和有限回测诊断，不能用于生成合规的人工交易计划。

## 实测覆盖

| 数据项 | 实测结果 | 缺口与适用边界 |
|---|---|---|
| 历史日线 | 4 只沪深股票各返回 4,080 行，日期 2010-01-04 至 2026-10-26；字段含 OHLC、成交量、成交额、`tradestatus`、`isST`。成交量按股、成交额按元映射。 | 是人工选定的四只代码，不是历史全市场池；早期退市和非当前证券不能据此代表总体。 |
| 后复权与复权因子 | 每只样本都返回 `adjustflag=1` 价格序列和单独因子文件；因子条数依证券而异（17–22）。信号使用后复权收盘，模拟成交和估值使用原始 OHLC。 | 仍须保留快照版本；当前回测不核算现金分红、送转、配股和持仓股数变化。 |
| 交易日历 | 2010-01-01 至 2026-10-26 返回 6,143 个日历日，其中 4,080 个开市日；四只股票和沪深 300 的行情日期均通过日历校验。 | BaoStock 日历服务的持续更新和未来日期覆盖尚未建立定时监控。 |
| 股票基础资料 | 全量接口返回 9,022 条、含 5,564 条 `type=1` 股票记录；其中 1,200 条全部资产类型记录有非空退市日。 | 表中上市/退市日期可用于基础区间判断，不等于逐日挂牌状态和所有特殊证券事件。 |
| 历史退市样本 | `SH600001` 基础资料记载退市日 2009-12-29；其历史日线查询在 2000-01-04 至 2009-12-29 返回 2,413 行，末日状态为 `tradestatus=0`。 | 这是单证券验证，不代表退市数据全覆盖。正式快照的四只样本都在 2010 年仍有行情。 |
| 日期股票列表 | `query_all_stock(day=...)` 对 2015-01-05、2020-01-02、2024-01-02 分别返回 3,232、4,570、6,529 条。 | 列表包含非股票证券，必须与基础资料的 `type=1` 关联；本次未抓取全区间逐日列表，不能声称已建立完整历史股票池。 |
| ST / 停牌 | 快照没有缺失 `isST` 与 `tradestatus`；停牌状态按 `tradestatus=0` 规范化。 | 需要对更多 ST 与长期停牌样本进行专项交叉核对。 |
| 涨跌停、板块和交易单位 | 当前 BaoStock 日线响应没有逐日涨跌停比例/价格；适配器将其保持为未知。 | 回测使用配置中的 10% 限价和 100 股交易单位假设；所有样本行都使用了规则回退。计划生成仍会要求完整点时规则。 |
| 更新、调用速度和费用 | 请求日志在快照清单记录每个接口的实际开始/结束时间。四只股票、指数、日历、全量基础表合计约 96 秒。没有 Token 或付费步骤。 | 官方页面提到访问统计与 IP 限制，但本次没有查到或实测到明确 QPS/每日配额；不能假设无限调用。免费说明不等同于数据再分发许可。 |

BaoStock 官方 API 入口列有每日更新、历史 A 股 K 线和访问统计说明：[API 文档入口](https://www.baostock.com/api/)。官方证券基础资料文档列出上市日、退市日、类型和状态：[证券基本资料](https://www.baostock.com/mainContent?file=stockBasic.md)。官方复权说明提供复权因子查询及按原始日线构造复权价格的示例：[复权因子](https://www.baostock.com/mainContent?file=factorInfo.md)。包版本、Alpha 标记、免费数据描述及无发布 provenance 可在 [PyPI 项目页](https://pypi.org/project/baostock/)核对。

Tushare 官方接口分别列出股票基础信息、交易日历、停复牌、涨跌停价和历史 ST 数据：[股票基础信息](https://tushare.pro/document/1?doc_id=25)、[交易日历](https://tushare.pro/document/2?doc_id=26)、[每日停复牌](https://tushare.pro/document/2?doc_id=214)、[每日涨跌停价](https://tushare.pro/document/2?doc_id=183)、[历史 ST 名单](https://tushare.pro/document/2?doc_id=397)。当前官方权限表显示 `stock_basic` 和 `stk_limit` 的门槛为 2,000 积分起，`stock_st` 为 3,000 起；日线 `daily` 为 120 起，通用复权行情 `pro_bar` 为 2,000 起。积分只是接口最低权限门槛，实际频次随积分变化；本机未安装 Tushare 且没有可用 Token，因此未验证任何账户权限，也不据此推断用户拥有访问权。[Tushare 积分权限表](https://tushare.pro/document/1?doc_id=108)

## 快照版本

真实数据写入 `.gitignore` 覆盖的本地目录：

```text
data/private/snapshots/baostock-20100101-20261026-v3/
```

`manifest.json` 记录供应商包版本、接口、请求时间、股票池、字段映射、覆盖范围和文件 SHA-256。原始响应位于 `raw/`，规范化行情为 `bars.csv`，独立基准为 `benchmark.csv`，日历为 `trading_calendar.csv`。示例中的原始行情、成交数据、持仓数据和输出文件均不提交 Git。

## 下一步数据门槛

在用此基线做策略判断前，需要扩展并审核按日期重建的全市场股票池，覆盖已退市证券；补齐逐日 ST、停复牌、涨跌停、板块和交易单位规则；校准公司行动与历史费用；并做多源抽样对账。若用户已有 Tushare 积分，可再逐项核验权限，不需要先购买。
