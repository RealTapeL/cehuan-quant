# 实验记录规范

每个回测记录 `experiment_id`、策略标识、完整配置 JSON 与 SHA-256、规范数据快照 SHA-256、Git 提交与工作区状态、数据起止日、生成时间、初始现金、交易明细、受阻订单、权益曲线和质量警告。回测输出位于 `outputs/experiments/<experiment_id>/`，`outputs/` 已加入 Git 忽略。

当前已输出固定规则基线按时间顺序划分的开发/验证/测试指标，以及可配置长度和步长的连续滚动窗口表现诊断。后者观察组合在多个时间段的稳定性，并计入窗口期间回测组合的交易和费用；它不重新训练模型、不重置组合，也不属于滚动样本外验证。规则基线没有拟合模型；测试段只有在策略规则和参数事先冻结时才可作为有效留出结果。

对按日期重建的股票池，使用 `cehuan backtest --universe data/private/universes/<snapshot-id>`。命令只保留相同交易日 `pool_status=STOCK_MEMBER` 的行情，再执行同一基线；未知类型成员会留在审计表中但不进入回测。运行 `cehuan universe-audit --universe <snapshot-dir> --bars <bars.csv>` 可查看逐日行情覆盖、停牌字段差异、未知 ST 和未来退市样本覆盖。缺失行情不会被补价格。

短区间的冻结策略敏感性比较用 `cehuan baseline-diagnostics --data <bars.csv> --universe <snapshot-dir> --benchmark-data <benchmark.csv> --cash 100000`。它保持策略规则不变，分别对照零费用、关闭未知涨跌停回退、1 股数量回退，以及把后复权信号改为原始收盘价。最后一项只说明信号构造敏感性；它不能替代现金分红、送转、配股或退市结算建模。完整指标、配置、成交、阻断订单与权益曲线均写入独立场景目录。

下一步仍需为有训练过程的模型实现真正的 walk-forward：每折仅用当时可得的训练和验证数据选模型，在之后的测试段冻结模型与参数，并按相同交易规则执行；还要在同一数据快照、股票池、费用和执行约束下比较 RD-Agent 候选。候选需保留代码提交、数据版本、训练区间、标签可得时间、参数、运行成本、样本外统计和人工审核决定。

2026-10-27 的小股票池真实数据流程与固定动量诊断记录在[数据源审计](data-provider-audit.md)和[真实数据基线报告](real-data-baseline.md)。该实验验证管道可以运行，但因股票池只有四只人工指定证券、交易规则与公司行动不完整，不能视为策略绩效评估或有效样本外结论。

点时全市场股票池已在 2024-10-08 至 2025-01-10 短区间核验；冻结策略收益、幸存股票子集、费用、规则回退及原始/后复权信号对照见[点时股票池核验记录](point-in-time-universe-validation.md)。更长的 2010–2026 股票池请求在第 50 个交易日遇到 BaoStock 网络重置，目前只保留断点；全历史比较尚未完成。短区间数据不是独立留出集，且没有公司行动现金/持股数会计。
