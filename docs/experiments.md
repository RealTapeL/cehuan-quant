# 实验记录规范

每个回测记录 `experiment_id`、策略标识、完整配置 JSON 与 SHA-256、规范数据快照 SHA-256、Git 提交与工作区状态、数据起止日、生成时间、初始现金、交易明细、受阻订单、权益曲线和质量警告。回测输出位于 `outputs/experiments/<experiment_id>/`，`outputs/` 已加入 Git 忽略。

当前已输出固定规则基线的按时间顺序开发/验证/测试区间指标。因为规则基线没有拟合模型，这些区间不是机器学习训练流程；测试段只有在策略规则和参数事先冻结时才可作为有效留出结果，也不等同于滚动样本外评估。下一步应实现滚动窗口与适用模型的训练/验证流程，并在同一数据快照、股票池、费用和执行约束下比较 RD-Agent 候选。候选需保留代码提交、数据版本、训练区间、标签可得时间、参数、运行成本、样本外统计和人工审核决定。
