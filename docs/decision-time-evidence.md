# 历史决策时点与运行时点证据

本文定义策环历史研究的时间证据口径，并记录一次真实历史行情 checkpoint 的脱敏审计结果。它不证明策略有效，不构成正式基线，也不提供个人交易建议。

## 必须区分的时间

- **实际运行时点**：程序读取本地输入、运行并生成产物的时间，由运行记录和文件系统证据支持。
- **历史模拟决策时点**：策略在模拟历史中的某一交易日何时形成信号、何时可以执行。
- **外部信息可得时点（`known_at`）**：行情、状态、规则或公告在当时首次可被策略取得的证据。
- **数据修订/版本时点**：供应商历史记录是否经过事后修订，以及本次数据对应哪个可证明的版本。

实际运行时间不能证明历史信息当时已公开。日期级 `available_at` 假设也不能替代供应商发布时间证据。

## 状态定义

| 状态 | 含义 |
|---|---|
| `POINT_IN_TIME_VERIFIED` | 有来源和时点证据支持该信息在对应决策时点已可用 |
| `DATE_ONLY` | 仅有日期，无法确认日内时间；不得自动视作盘前可得 |
| `CURRENT_HISTORICAL_SNAPSHOT` | 后来取得的历史数据快照，缺少当时可见版本证明 |
| `UNVERIFIED` | 关键来源、时间或版本证据缺失 |
| `FAILED` | 出现明确的时间冲突、来源冲突或绑定不一致 |

策略配置可以证明“策略约定了什么截止时点”，但不能单独证明外部数据在该时点可得。文件哈希、规范化摘要和 checkpoint 绑定只证明字节或计算链的一致性，不证明公告解读正确或历史 vintage 完整。

## 未来运行记录契约

每个模拟决策至少记录：

```text
decision_date
decision_cutoff_utc
decision_timezone
decision_timing_rule
decision_timing_rule_version
execution_earliest_at
source_available_at_status_by_input_family
source_retrieved_at_utc_by_input_family
source_revision_or_vintage_id
```

每项外部来源另有可核验来源、原始文件散列、适用日期、首次可得时间证据、人工复核状态。没有时间证据时保留 `DATE_ONLY` 或 `UNVERIFIED`，不得根据有效日期推断发布时间。对旧 checkpoint 不回填推测的精确截止时点；缺少时点证据时继续阻断增量续跑。

## 已审计短窗口的结论

本次只读审计覆盖 2024-10-08 至 2025-01-10 的 68 个模拟交易日。实验实际在 2026 年生成；输入行情、股票池和日历也在 2026 年采集。模拟策略依据代码是在 t 日收盘形成信号、最早次交易日开盘执行，但旧运行没有历史日内截止时点的外部证据。

- 68 个行级 `available_at` 时间是适配器生成的“交易日 15:00（Asia/Shanghai）”假设，不是 BaoStock 当年发布时间证据。
- 日期专属股票池响应在历史窗口之后采集；日期对应关系不证明供应商当时可见版本或后续修订状态。
- checkpoint 的下一开市日与输入日历计算结果一致；日历本身在窗口后采集，历史版本仍未验证。
- checkpoint 与已提供输入的字节散列、规范化绑定及单段历史行情链可重建；来源登记表文件散列匹配但登记数据行数为 0。来源内容审核和 `known_at` 证据仍为 `UNVERIFIED`。
- 评价行情行缺少有效日期市场规则；本次模拟成交全部采用配置回退。未绑定历史费率表，回退值不是历史费率或华泰个人费率。
- 身份与公司行动登记表在本窗口没有匹配的已登记阶段事件，但登记表不是全面公告源。不能将“没有登记事件”解释成“市场没有事件”；持仓和候选的公司行动覆盖仍未验证。
- 旧信号行情请求使用 BaoStock `adjustflag=1` 后复权，与当时配置的 `hfq` 口径一致。该快照在模拟历史窗口后采集；供应商历史 vintage、后续修订和当年首次可得时间仍未验证。

完整私有路径、逐行散列及逐笔回退细节保存在本机忽略目录下的审计产物中，不进入 Git。

## 配股调度测试盘点

配股测试使用合成事件，不代表本窗口发现或核验了真实配股公告。

- 已覆盖：精确整数权利认购与现金扣减、现金不足时原子拒绝、认购后的待登记权利、登记批次、可流通日前不可卖、重复登记幂等、登记/认购阶段 checkpoint 连续与分段一致、登记日无持仓时权利取消，以及调度层缺少决策和 `MANUAL_REVIEW` 的显式状态。
- 本轮补充：`DECLINE` 通过完整回测引擎并跨 checkpoint 保持一致；非整数权利必须提供整数获配数和依据；低于精确权利边界的部分认购请求明确拒绝且不改账。
- 尚不支持：将“申购数量”与“最终获配数量”分开表示，因此部分认购不是当前模型能力。配股与同一证券代码变更发生在同一窗口的交互也尚未单独验证，不能据此声称已覆盖。

这些合成测试不提供真实行情、公告或券商分配证据；正式基线仍保持 `NOT_READY`。

## 发布与使用边界

这次审计证明的是输入绑定和历史行情链可被重建，不证明输入在模拟历史时点可得。正式基线保持 `NOT_READY`；增量续跑 `can_continue=false`，引擎恢复仍关闭。此报告没有运行策略、生成个人交易计划、连接华泰或执行下单。

复权字段及研究限制见 [BaoStock Python API 文档](https://www.baostock.com/baostock/index.php/Python_API%E6%96%87%E6%A1%A3)和[复权因子说明](https://www.baostock.com/mainContent?file=factorInfo.md)。接口覆盖和其他数据限制见[数据源审计](data-provider-audit.md)。
