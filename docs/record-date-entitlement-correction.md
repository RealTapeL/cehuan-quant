## 更正内容

此前逐笔审计把“登记日买入不享有权益、登记日卖出仍可享有”当作普通 A 股通用口径，主要依据一份 2006 年《T+1 日货银对付登记结算业务指南（测试用稿）》。该指南确实给出这一处理示例；深交所 2006 年全网测试通知也要求参测单位按该测试用稿准备测试。但测试材料自身标为“测试用稿”，不能单独证明其具体表述就是 2024 年所有市场、证券类型和公司行动的现行处理规则。

深交所投资者教育页面则明确写到：在股权登记日买入股票可享有该次分红或配股权益，除权除息日买入不享有本次权益。中国结算深圳分公司发行人业务指南确认，A 股权益分派的 R 日为权益登记日；中国证监会《证券登记结算管理办法》第二十九条规定，证券持有人名册按证券交易交收结果办理变更登记。上述一般规则并没有在同一份现行材料中把登记日当日买卖对每类公司行动的账户级结果逐项说清，因此本项目不把任一简化描述扩展成覆盖沪深、普通股、基金、配股和其他证券的统一结论。

本次代码采用**模拟审计工作口径**：按回测中登记日收盘后的持仓区间寻找“可能匹配”的事件。该口径让登记日买入且收盘仍持有的模拟持仓进入候选匹配；登记日收盘前已平仓的模拟持仓不进入。它是可复现的研究假设，并非中国结算账户记录的替代品。真实事件只有在对应市场、证券类型和具体实施公告的证据核对完成后，才可用于实际账务解释；证据未核实的情况继续阻断正式基线。

## 复核的边界案例

| 合成情形 | 快照/匹配预期 |
|---|---|
| 登记日前已有持仓，登记日不交易 | 当日收盘持仓进入可能匹配和账本权益快照 |
| 登记日买入并持有至模拟收盘 | 按当前研究工作口径进入可能匹配和权益快照 |
| 登记日部分卖出 | 剩余模拟持仓进入权益快照 |
| 登记日全部卖出 | 当日收盘无持仓，不进入该模拟工作口径的快照 |
| 登记日后卖出 | 已锁定的权益快照保持不变 |
| 登记日多笔买卖 | 按所有当日模拟成交后的持仓总量入账，不按成交笔数重复计权 |
| 登记日快照后恢复账本 | 权益数量及事件归属不重复、不丢失 |

若现行结算业务材料、特定实施公告或账户持有人记录与本模拟假设不同，应先记录适用市场、证券类型、事件类型和生效日期，再另行调整事件适配与回测；不能通过修改单条测试预期来掩盖来源冲突。
