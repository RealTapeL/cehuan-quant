# 华泰成交字段调查

状态：未取得并核验脱敏华泰成交样本。此表只是调查模板，不表示项目已识别华泰导出的字段语义，也不接到账户盈亏计算。

填写 [字段调查 CSV](evidence/huatai-fill-field-investigation-template.csv) 时，请在本机复制文件并填写，不要把账户号、姓名、身份证号或原始交割单提交到公开仓库。每个源列分别记录字段含义、成交编号唯一范围、时间精度、修正/冲正关联、费用语义和证据散列。

成交去重仍是审查模式：没有样本证明稳定成交编号以前，只能报告疑似重复；不得因成交时间、方向、数量和价格相同就自动合并。此模板也不授权把分类结果写入真实账户账本。
